Essential TallyPrime Keyboard Shortcuts

Industry professionals rely entirely on the keyboard. Master these essential keys:

Shortcut Action / Function Context / Screen
T Continue in Educational Mode Tally Startup Screen (No License Required)
Alt + G Go To (Universal Search) Anywhere in TallyPrime for instant reporting & multitasking
Ctrl + H Change Mode Toggle Single Entry, Double Entry, Item/Accounting Invoice
F2 Change Date In Edu mode, enter 1, 2, or 31
Alt + F2 Change Period Set Financial Year window (e.g. 1-Apr-25 to 31-Mar-26)
F4 to F9 Voucher Types F4 Contra • F5 Payment • F6 Receipt • F7 Journal • F8 Sales • F9 Purchase
Ctrl + A Save / Accept Instantly Accepts voucher, ledger, or configuration without pressing enter repeatedly
Alt + C Create On-The-Fly Creates new ledger, stock item, or tax head directly inside voucher fields
Alt + F5 / Alt + F6 Debit Note / Credit Note Purchase return (Alt + F5) and Sales return (Alt + F6)
Esc Quit / Step Back Returns to previous menu or Gateway of Tally
