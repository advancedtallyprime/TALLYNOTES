1. Core Concept

  • Purchase Order (PO): A formal commitment placed with a supplier to purchase goods at a specified rate and future date. It tracks pending orders without affecting accounting ledgers or stock balances directly.
  • Purchase Invoice (F9): The financial voucher recording the actual bill and receipt of goods, which directly updates stock and accounting ledgers.
The TallyPrime Purchase Cycle:
Purchase Order (Ctrl + F9) → Receipt Note / Goods Inward (Alt + F9)* → Purchase Invoice (F9)
*(Note: Linking PO directly to Invoice is standard when Receipt Notes aren't used)*.
Educational Mode Purchase Order & Invoice Guide:
  • Enable Order Processing in F11 → Enable Purchase Order Processing = Yes.
  • Open Purchase Order via Ctrl + F9 (or F10 Other Vouchers → Purchase Order).
  • Enter PO on 01-May with Due On date as 01-May or 02-May.
  • When recording Purchase Invoice (F9) on 02-May, select the Order No. from Order Details to auto-fill all items!

2. Feature Activation in TallyPrime

Step A: Enable Order Processing

  1. Press F11 (Features) on the Gateway of Tally.
  2. Set Enable Purchase Order Processing to Yes.
  3. Set Enable Sales Order Processing to Yes.
  4. Press Ctrl + A to save.

Step B: Activate Voucher Type (If Inactive)

  • Method 1 (Fastest): Go to Vouchers → Press F10 (Other Vouchers) → Select Purchase Order (Shortcut: Ctrl + F4). When prompted to activate, press Y or select Yes.
  • Method 2: Gateway of Tally → Alter → Voucher Type → Purchase Order → Set Activate this Voucher Type to Yes → Save with Ctrl + A.

3. How to Record Vouchers

Recording Purchase Orders (Ctrl + F9 )

  1. Go to Gateway of Tally → Vouchers → Press Ctrl + F9 (Purchase Order).
  2. Select Party A/c Name (Supplier).
  3. Enter Order No.
  4. Select the Purchase Ledger.
  5. Select Stock Item, enter Due On date, Quantity, and Rate.
  6. Enter Narration: BEING ORDER PLACED.
  7. Press Ctrl + A to save.

Recording Purchase Invoices (F9)

  1. Go to Gateway of Tally → Vouchers → Press F9 (Purchase).
  2. Enter Supplier Invoice No. and Invoice Date.
  3. Select Party A/c Name.
  4. In the Order Details screen, select the corresponding Order No. (item details will auto-fill).
  5. Enter Narration: Being goods purchased on credit.
  6. Press Ctrl + A to save.

5. Checking, Deleting & Modifying Vouchers

To Check / Delete / Modify Purchase Orders:

  • Navigation Path:
    Gateway of Tally → Display More Reports → Inventory Books → Purchase Orders Book
    (Shortcut: Press Alt + G → Type Purchase Order Book)
  • Action: Select the month → Press Enter on the voucher to view or modify. Press Alt + D inside the voucher to delete it.

To Check / Delete / Modify Purchase Invoices:

  • Navigation Path:
    Gateway of Tally → Display More Reports → Account Books → Purchase Register
    (Shortcut: Press Alt + G → Type Purchase Register)
  • Action: Select the month → Press Enter on the voucher to edit details or press Alt + D to delete.
