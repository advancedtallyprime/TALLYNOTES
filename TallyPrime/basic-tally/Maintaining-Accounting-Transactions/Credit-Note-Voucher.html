1. Core Concept

  • Credit Note: A document issued to a customer (Debtor) when they return goods previously sold, or when allowing a price adjustment/discount on a past invoice.
  • Accounting Impact: It reduces your accounts receivable (asset) from the customer and increases your available stock balance.
The TallyPrime Return Cycle:
Sales Invoice (F8) → Credit Note / Sales Return (Alt + F6)
(Note: In TallyPrime, the default shortcut for Credit Note is Alt + F6).
Educational Mode Credit Note Guide:
  • Press Alt + F6 (Credit Note) to record sales returns from customers.
  • Enter date as 01-Apr or 02-Apr (F2).
  • Select original Sales Invoice reference and provide reason for return.

2. Feature Activation in TallyPrime

Step A: Enable Debit & Credit Notes

  1. Press F11 (Features) on the Gateway of Tally.
  2. Under Accounting Features, set Enable Debit and Credit Notes to Yes.
  3. Press Ctrl + A to save.

Step B: Activate Voucher Type (If Inactive)

  • Method 1 (Fastest): Go to Vouchers → Press F10 (Other Vouchers) → Select Credit Note (Shortcut: Alt + F6). When prompted to activate, press Y or select Yes.
  • Method 2: Gateway of Tally → Alter → Voucher Type → Credit Note → Set Activate this Voucher Type to Yes → Save with Ctrl + A.

3. How to Record Vouchers

Recording Credit Notes (Alt + F6)

  1. Go to Gateway of Tally → Vouchers → Press Alt + F6 (Credit Note).
  2. Select Party A/c Name (Customer / Debtor).
  3. In the Original Invoice Details pop-up, enter the original Reference No. (e.g., S-101) and Invoice Date.
  4. Select the Sales / Sales Return Ledger.
  5. Select Stock Item, enter Quantity, and Rate (Total amount auto-calculates).
  6. Enter Narration: Being goods received.
  7. Press Ctrl + A to save.

5. Checking Effect & Report Verification

To Check Effect on Outstanding Receivables:

  • Navigation Path:
    Gateway of Tally → Display More Reports → Statements of Accounts → Outstandings → Receivables
    (Shortcut: Press Alt + G → Type Receivables)

To Check / Delete / Modify Credit Notes:

  • Navigation Path:
    Gateway of Tally → Display More Reports → Account Books → Journal Register → Credit Note Register
    (Shortcut: Press Alt + G → Type Credit Note Register)
  • Action: Select the month → Press Enter on the voucher to view or edit details. Press Alt + D inside the voucher to delete it.
