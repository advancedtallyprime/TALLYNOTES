1. Core Concept

  • Sales Order (SO): A formal commitment received from a customer to buy goods at a specified rate and future date. It tracks pending customer orders without affecting accounting ledgers or stock balances directly.
  • Sales Invoice (F8): The financial voucher recording the actual bill and dispatch of goods, which directly updates stock and accounting ledgers.
The TallyPrime Sales Cycle:
Sales Order (Ctrl + F8) → Delivery Note / Goods Outward (Alt + F8)* → Sales Invoice (F8)
*(Note: Linking SO directly to Invoice is standard when Delivery Notes aren't used)*.
Educational Mode Sales Order & Invoice Guide:
  • Enable Sales Order Processing in F11 Features = Yes.
  • Press Ctrl + F8 (or F10 → Sales Order) and record order on 01-Apr.
  • Press F8 (Sales Invoice) on 02-Apr and select the Sales Order number to track pending orders.

2. Feature Activation in TallyPrime

Step A: Enable Order Processing

  1. Press F11 (Features) on the Gateway of Tally.
  2. Set Enable Purchase Order Processing to Yes.
  3. Set Enable Sales Order Processing to Yes.
  4. Press Ctrl + A to save.

Step B: Activate Voucher Type (If Inactive)

  • Method 1 (Fastest): Go to Vouchers → Press F10 (Other Vouchers) → Select Sales Order (Shortcut: Ctrl + F5). When prompted to activate, press Y or select Yes.
  • Method 2: Gateway of Tally → Alter → Voucher Type → Sales Order → Set Activate this Voucher Type to Yes → Save with Ctrl + A.

3. How to Record Vouchers

Recording Sales Orders (Ctrl + F8)

  1. Go to Gateway of Tally → Vouchers → Press Ctrl + F8 (Sales Order).
  2. Select Party A/c Name (Customer).
  3. Enter Order No.
  4. Select the Sales Ledger.
  5. Select Stock Item, enter Due On date, Quantity, and Rate.
  6. Enter Narration: being order received.
  7. Press Ctrl + A to save.

Recording Sales Invoices (F8)

  1. Go to Gateway of Tally → Vouchers → Press F8 (Sales).
  2. Select Party A/c Name.
  3. In the Order Details screen, select the corresponding Order No. (item details will auto-fill).
  4. Enter Reference No.
  5. Enter Narration: Being goods sold on credit.
  6. Press Ctrl + A to save.

5. Checking, Deleting & Modifying Vouchers

To Check / Delete / Modify Sales Orders:

  • Navigation Path:
    Gateway of Tally → Display More Reports → Inventory Books → Sales Orders Book
    (Shortcut: Press Alt + G → Type Sales Order Book)
  • Action: Select the month → Press Enter on the voucher to view or modify. Press Alt + D inside the voucher to delete it.

To Check / Delete / Modify Sales Invoices:

  • Navigation Path:
    Gateway of Tally → Display More Reports → Account Books → Sales Register
    (Shortcut: Press Alt + G → Type Sales Register)
  • Action: Select the month → Press Enter on the voucher to edit details or press Alt + D to delete.
