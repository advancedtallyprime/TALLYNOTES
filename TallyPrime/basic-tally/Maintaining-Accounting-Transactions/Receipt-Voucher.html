1. Core Concept

Receipt Voucher (F6): Used to record all incoming cash or bank receipts into the business.

Common Use Cases:

  • Receiving payments from debtors/customers against sales invoices (Bill-by-Bill settlement).
  • Capital introduced by the owner/proprietor.
  • Receiving interest, commission, or other indirect income.
Accounting Impact:
Debit → Cash / Bank Account
Credit → Giver / Customer / Income Account
Educational Mode Receipt Voucher Tip:
  • Press F6 for Receipt voucher.
  • Set transaction date using F2 to 1-4, 2-4, or 31-5.
  • Credit the Customer ledger / Income ledger and Debit Cash or Bank account.

2. How to Record Receipt Vouchers in TallyPrime

  1. Go to Gateway of Tally → Vouchers → Press F6 (Receipt).
  2. Select Mode: Press Ctrl + H to choose between Single-Entry Mode (easiest for cash/bank receipts) or Double-Entry Mode (Debit/Credit).
  3. Select Receipt Account: Choose Cash or Bank Account in the Account field.
  4. Select Party: Under Particulars, select the customer ledger (e.g., Deepak Creation).
  5. Bill-wise Settlement:
    • In the Bill-wise Details pop-up, select Agst Ref (Against Reference).
    • Select the corresponding Sales Invoice Reference Number (e.g., S-103 / Ref 3).
  6. Enter the Amount being received.
  7. Fill in Narration: Being amount received.
  8. Press Ctrl + A to save.

4. Checking Effect & Report Verification

To View Statistics & Receipt Count:

  • Navigation Path:
    Gateway of Tally → Display More Reports → Statements of Accounts → Statistics → Select Receipt
    (Shortcut: Press Alt + G → Type Statistics → Drill down into Receipt)

To Check / Delete / Modify Receipt Entries:

  • Navigation Path:
    Gateway of Tally → Display More Reports → Account Books → Receipt Register
    (Shortcut: Press Alt + G → Type Receipt Register)
  • Action: Select the month → Press Enter on the transaction to view or edit details. Press Alt + D inside the voucher to delete it.
