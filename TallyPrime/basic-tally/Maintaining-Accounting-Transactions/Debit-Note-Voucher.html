1. Core Concept

  • Debit Note: A document issued to a supplier (Creditor) when returning goods previously purchased, or to adjust an overcharged invoice amount.
  • Accounting Impact: It reduces your accounts payable (liability) to the supplier and decreases your stock balance.
The TallyPrime Return Cycle:
Purchase Invoice (F9) → Debit Note / Purchase Return (Alt + F5)
(Note: In TallyPrime, the default shortcut for Debit Note is Alt + F5).
Educational Mode Debit Note Guide:
  • Press Alt + F5 (Debit Note) to record purchase returns to suppliers.
  • Enter date as 01-Apr or 02-Apr (F2).
  • Select original Purchase Invoice reference under Bill-wise details.

2. Feature Activation in TallyPrime

Step A: Enable Debit & Credit Notes

  1. Press F11 (Features) on the Gateway of Tally.
  2. Under Accounting Features, set Enable Debit and Credit Notes to Yes.
  3. Press Ctrl + A to save.

Step B: Activate Voucher Type (If Inactive)

  • Method 1 (Fastest): Go to Vouchers → Press F10 (Other Vouchers) → Select Debit Note (Shortcut: Alt + F5). When prompted to activate, press Y or select Yes.
  • Method 2: Gateway of Tally → Alter → Voucher Type → Debit Note → Set Activate this Voucher Type to Yes → Save with Ctrl + A.

3. How to Record Vouchers

Recording Debit Notes (Alt + F5)

  1. Go to Gateway of Tally → Vouchers → Press Alt + F5 (Debit Note).
  2. Select Party A/c Name (Supplier / Creditor).
  3. In the Original Invoice Details pop-up, enter the original Supplier Invoice No. (e.g., P-101) and Invoice Date.
  4. Select the Purchase / Purchase Return Ledger.
  5. Select Stock Item, enter Quantity, and Rate (Total amount auto-calculates).
  6. Enter Narration: Being goods return.
  7. Press Ctrl + A to save.

5. Checking Effect & Report Verification

To Check Effect on Outstanding Payables:

  • Navigation Path:
    Gateway of Tally → Display More Reports → Statements of Accounts → Outstandings → Payables
    (Shortcut: Press Alt + G → Type Payables)

To Check / Delete / Modify Debit Notes:

  • Navigation Path:
    Gateway of Tally → Display More Reports → Account Books → Journal Register → Debit Note Register
    (Shortcut: Press Alt + G → Type Debit Note Register)
  • Action: Select the month → Press Enter on the voucher to view or edit details. Press Alt + D inside the voucher to delete it.
