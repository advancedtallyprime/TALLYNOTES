1. Core Concept: The 3 Configuration Levels

To enable seamless auto-deduction in transactions, TDS must be configured systematically across three architectural levels in TallyPrime:

Configuration Level Entity Configured What is Defined
Level 1: Expense Ledger Ledgers like Rent Expense, Audit Fees, Contract Charges Mark Is TDS Applicable? = Applicable; assign Default Nature of Payment.
Level 2: Party Ledger Vendors / Creditors like KPMG & Co., Landlord Realty Mark Is TDS Deductible? = Yes; Deductee Type (Company / Individual); specify PAN!
Level 3: Tax Duty Ledger Tax ledgers like TDS on Professional Fees, TDS on Rent Type of Duty = TDS; select Nature of Payment.

2. Detailed Party Ledger Configuration (Crucial)

  1. Go to Create → Ledger (e.g. Apex Architects under Sundry Creditors).
  2. Set Maintain balances bill-by-bill to Yes.
  3. Set Is TDS Deductible? to Yes.
  4. Select Deductee Type: Company Resident (or Individual / HUF Resident).
  5. Set Deduct TDS in Same Voucher: Yes (automatically deducts TDS on the same invoice!).
  6. PAN/IT No.: Enter valid 10-character PAN (e.g., AAACA1234F). Without PAN, Tally will deduct tax at the penal 20% rate!

3. Interview Questions & Answers

Q1. What happens if a party's PAN is not entered in their ledger master?

Ans: TallyPrime triggers Section 206AA provisions and automatically deducts TDS at the higher penal rate of 20% instead of standard 1% / 2% / 10%.
