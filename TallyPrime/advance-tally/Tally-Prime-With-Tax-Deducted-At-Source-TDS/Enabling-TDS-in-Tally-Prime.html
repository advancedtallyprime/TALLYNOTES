1. Core Concept

Enabling TDS in TallyPrime activates statutory deduction algorithms, auto-computes withholding amounts during voucher entries, generates Challan ITNS 281 payment details, and compiles Form 26Q returns.

2. Step-by-Step Activation via F11 Features

Activation Path: Gateway of Tally → Press F11 (Features) → Taxation Section.
  1. From Gateway of Tally, press F11.
  2. Under Taxation, set Enable Tax Deducted at Source (TDS) to Yes.
  3. In the TDS Details configuration sub-screen, enter:
    • Tax Assessment Number (TAN): E.g., BLRN12345F
    • Tax Deduction and Collection Account Number (TAN): E.g., BLRN12345F
    • Deductor Type: Select Company or Individual / HUF.
    • Deductor Branch / Division: E.g., Head Office, Bengaluru.
    • Set/alter details of person responsible: Set to Yes → Enter name, father's name, designation, PAN, and address of the Principal Officer / Managing Director responsible for tax compliance.
    • Ignore TDS Exemption limit for TDS rate: Set to No (allows threshold tracking).
    • Activate TDS for stock items: Set to No (unless dealing in specified goods).
  4. Press Ctrl + A to save statutory details.

3. Interview Questions & Answers

Q1. Which function key enables TDS in TallyPrime?

Ans: F11 (Company Features) → Enable Tax Deducted at Source (TDS) = Yes.
