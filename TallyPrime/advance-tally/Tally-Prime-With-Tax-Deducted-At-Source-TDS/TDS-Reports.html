1. Core Concept of TDS Reports & e-Filing

TallyPrime compiles all TDS deductions, party PAN details, and Challan 281 payments into official statutory return formats (Form 26Q for non-salary deductions and Form 27Q for non-resident payments) ready for quarterly e-filing.

2. Accessing Form 26Q in TallyPrime

Navigation: Gateway of Tally → Display More Reports → Statutory Reports → TDS Reports → Form 26Q.
Shortcut: Alt + G → Type Form 26Q.

3. Form 26Q Triangulation Summary Structure

Section in Form 26Q What it Displays Required Auditor Action
Total Deductions Total count and gross value of all expense transactions eligible for TDS. Verify against Trial Balance expense balances.
Deductions at Normal Rate Transactions where tax was deducted at standard rates with valid PANs. Clean pool ready for return filing.
Deductions at Higher Rate Deductions at 20% due to invalid / missing PANs under Section 206AA. Collect PANs from vendors before quarter closes.
Uncertain Transactions (Correction Needed) Transactions with missing details (e.g. missing PAN, invalid section code, unrecorded challan BSR). Must be ZERO before generating the e-return! Press Enter to resolve inline.

4. Generating the e-TDS Text File for NSDL Validation

  1. Ensure Uncertain Transactions is exactly 0.
  2. Press Alt + E (Export) → E-Return.
  3. Specify export directory. Tally generates the standardized .txt e-TDS return data file.
  4. Run the text file through the official File Validation Utility (FVU) provided by Protean / NSDL.
  5. Upload the generated .fvu file directly to the Income Tax e-Filing portal!

5. Interview Questions & Answers

Q1. What must an accountant do if Form 26Q shows 5 "Uncertain Transactions"?

Ans: Press Enter on Uncertain Transactions to drill down, identify the missing details (such as missing PAN or unlinked Challan 281), fill in the correct information directly from the correction screen until the count drops to zero.

Q2. What is Form 16A?

Ans: Form 16A is the quarterly TDS certificate issued by the deductor to the deductee for non-salary payments, downloadable from the TRACES portal after Form 26Q is processed.
