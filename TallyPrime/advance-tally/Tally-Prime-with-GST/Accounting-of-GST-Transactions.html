GST Accounting ka Basic Concept

GST accounting ko samajhne ke liye do important sides hain:

  • Purchafrom Side: Business jab GST pay karke goods/services purchafrom karta hai, eligible conditions ke subject to GST amount Input Tax Credit (ITC) ke roop in relevant ho sakta is.
    Example: Purchafrom = ₹10,000 | GST @18% = ₹1,800 | Invoice = ₹11,80Yahan ₹1,800 purchafrom side ka GST component is.
  • Sales Side: Business jab taxable goods/services sell karta hai, applicable GST customer from collect karta is.
    Example: Sales = ₹20,000 | GST @18% = ₹3,600 | Customer from = ₹23,60Yahan ₹3,600 output GST liability ka component ho sakta is.

Purchafrom GST vs Sales GST

Particular Purchase Sales
Business kor karta hai? Goods/Services kharidta hai Goods/Services bechta hai
GST ka basic effect Input GST Output GST
Example Purchafrom ₹10,000 + GST Sale ₹20,000 + GST
GST @18% ₹1,800 ₹3,600
Invoice Total ₹11,800 ₹23,600
Easy Formula:
Purchase: Purchafrom Value + Input GST = Invoice Value
Sales: Sales Value + Output GST = Invoice Value

Intra-State vs Inter-State Concepts

  • Intra-State Purchase: Supplier and buyer same State in are.
    Example: ABC Traders (Maharashtra) purchases from XYZ Suppliers (Maharashtra).
    Taxable Value = ₹10,000 | GST @18% → CGST (9%) = ₹900, SGST (9%) = ₹900 | Invoice Value = ₹11,800.
  • Inter-State Purchase: Supplier dusre State ka is.
    Example: ABC Traders (Maharashtra) purchases from Delhi Suppliers (Delhi).
    Taxable Value = ₹10,000 | GST @18% → IGST = ₹1,800 | Invoice Value = ₹11,800.
  • Intra-State Sales: Same State ke customer ko sale karna.
    Example: ABC Traders (Maharashtra) sells to Maharashtra Customer.
    Taxable Value = ₹20,000 | GST @18% → CGST (9%) = ₹1,800, SGST (9%) = ₹1,800 | Invoice Value = ₹23,600.
  • Inter-State Sales: Other State ke customer ko sale karna.
    Example: ABC Traders (Maharashtra) sells to Gujarat Customer.
    Taxable Value = ₹20,000 | GST @18% → IGST = ₹3,600 | Invoice Value = ₹23,600.

Important Accounting Flow

Purchafrom Flow: Supplier → ABC Traders → Purchafrom Value + GST → Input GST → Eligible ITC (subject to rules)

Sales Flow: ABC Traders → Customer → Sales Value + GST → Output GST → Tax Liability

Common Mistakes & FAQs

Common Mistakes:

  • Party State Wrong: Supplier/Customer ka State galat choofrom karna GST calculation ko corrupt kar deta is.
  • Voucher Confusion: Purchafrom (F9) and Sales (F8) in galat voucher type select karna.
  • Wrong Tax Selection: Same-state in IGST or different-state in CGST/SGST ufrom karna.
  • Taxable Value vs Invoice Value: Taxable value par tax calculate is, invoice total par nahi.
  • Forcing GST Manually: Taxes manually overwrite karne ke bajaye configuration masters check execute.

Frequently Asked Questions:

  • Q: Local purchase/sale in kaunsa tax lagega?
    A: CGST + SGST (Central + State GST).
  • Q: Interstate purchase/sale in kaunsa tax lagega?
    A: IGST (Integrated GST).
  • Q: GST calculate karne ka formula kor hai?
    A: GST = Taxable Value × GST Rate ÷ 100.
  • Q: Agar TallyPrime in GST auto calculate na ho toh kor check execute?
    A: Check Company State, Party State, Registration Type, GSTIN, Stock Item HSN & Rate, and Voucher configuration.
