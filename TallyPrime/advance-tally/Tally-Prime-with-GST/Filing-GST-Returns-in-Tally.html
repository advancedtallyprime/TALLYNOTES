Return Generation vs Return Filing

Accounting software data preparation and statutory portal submission dono separate stages hain:

  • Return Generation (TallyPrime): Accounting vouchers and registers from statutory tables (B2B, B2C, ITC, HSN) ko compile karke JSON/Excel file format in export karna.
  • Return Filing (GST Portal): Prepared JSON file ko gst.gov.in par upload karna, data validate karna, tax liability offset karna, and DSC/EVC ke through ARN (Application Reference Number) generate karna.

Purchase/Sales Vouchers → TallyPrime Triangulation → GSTR-1 JSON Export → Portal Upload & Validation → GSTR-1 Submission → GSTR-3B ITC Set-off → Cash Payment → GSTR-3B File → ARN Generated

GSTR-1 Export, Portal Upload & Submission

Step A: Export JSON from TallyPrime

  1. Go to Gateway of Tally → Display More Reports → GST Reports → GSTR-1.
  2. Verify that Uncertain Transactions (Corrections Needed) is 0.
  3. Press Alt + E (Export) → Select GST Returns → File Format: JSON → Save file (e.g., GSTR1_ABC_TRADERS.json).

Step B: Upload & File on GST Portal

  1. Login to gst.gov.in → Navigate to Returns Dashboard → Select Financial Year & Return Period.
  2. Under GSTR-1, click Prepare Offline → Upload JSON file.
  3. Wait for portal validation status to show Processed.
  4. Click Generate Summary → Review Table totals (B2B, B2C, HSN) → Click Submit.
  5. File with EVC (OTP) or DSC (Digital Signature Certificate) to receive the ARN.

GSTR-3B Tax Offset & Filing Workflow

Step A: Tax Liability Offset & Payment

  1. Open GSTR-3B on the GST Portal.
  2. Auto-populated outward liabilities (from GSTR-1) and auto-drafted ITC (from GSTR-2B) verify execute.
  3. Click Proceed to Payment → If cash balance is insufficient, generate Challan (PMT-06) for ₹12,600 and deposit funds via Net Banking.
  4. Click Make Payment / Set Off Liability.

Step B: Final GSTR-3B Filing

  1. Check declaration box → Select Authorized Signatory.
  2. Click File GSTR-3B with EVC / DSC.
  3. Save filing acknowledgement receipt containing the ARN.

Common Portal Upload Errors & Solutions

  • Error: Invalid GSTIN Format / Checksum: Customer ledger in GSTIN re-check execute and voucher re-save karke fresh JSON export execute.
  • Error: Duplicate Invoice Number: Check if an invoice with the same number was already uploaded in a previous batcEnsure unique invoice numbering.
  • Error: Tax Amount Mismatch: Tally in Tax Analysis screen (Ctrl + O) check karke round-off issues fix execute.

Verification Reports, Common Mistakes & FAQs

Verification Reports in TallyPrime:

  • GSTR-1 & GSTR-3B Triangulation Summary: Ensure Included in Returns matches all recorded vouchers.
  • GST Computation: Cross-check balance liability against Electronic Cash/Credit Ledgers.
  • Electronic Return Export Log: Maintain a backup of exported JSON files with respective ARNs.

Common Mistakes:

  • Attempting to upload JSON while transactions remain under Uncertain Transactions (Corrections Needed).
  • Submitting GSTR-1 without verifying B2B invoice GSTINs against the official GST portal portal cache.
  • Attempting to file GSTR-3B before setting off liability in cash/credit ledgers.
  • Failing to save and archive the ARN acknowledgement after successful submission.

Frequently Asked Questions:

  • Q: Return generate karna and return file karna in kor antar hai?
    A: Generate karna TallyPrime in data prepare karna hai, jabki file karna us data ko GST portal par submit karke ARN generate karna is.
  • Q: ARN ka full form kor hai?
    A: Application Reference Number — yeh return successfully file hone ka unique statutory proof is.
  • Q: Kor TallyPrime direct bina portal login kiye return submit kar deta hai?
    A: TallyPrime return data export and API upload support karta hai, lekin final submission and verification (EVC/DSC) portal authentication ke through complete is.
