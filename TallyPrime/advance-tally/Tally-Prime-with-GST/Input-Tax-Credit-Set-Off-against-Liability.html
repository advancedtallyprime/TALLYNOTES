Quick Recap & Core Concepts: ITC Set Off

Input GST: Purchafrom ke time par suppliers ko pay kior gaor tax (Business Asset / Credit).

Output GST: Sales ke time par customers from collect kior gaor tax (Business Liability).

Core Formula:
Net GST Payable = Output GST Liability − Eligible Input Tax Credit (ITC)

Statutory GST Set Off & Cross-Utilization Rules

IGST Credit Utilization Priority:

  • 1st: Set off against IGST Liability
  • 2nd: Set off against CGST Liability
  • 3rd: Set off against SGST Liability

CGST Credit Utilization Priority:

  • 1st: Set off against CGST Liability
  • 2nd: Set off against IGST Liability
  • Restriction: CGST credit cannot be used to pay SGST.

SGST Credit Utilization Priority:

  • 1st: Set off against SGST Liability
  • 2nd: Set off against IGST Liability
  • Restriction: SGST credit cannot be used to pay CGST.
Absolute Golden Rule:
CGST ITC ≠ SGST Liability
SGST ITC ≠ CGST Liability
CGST and SGST credits aapas in cross-utilize nahi ho sakte.

Practical Scenarios & Set Off Walkthroughs

Scenario 1: Local Purchafrom + Local Sale

  • 01-Apr (Purchafrom F9): Purchased goods ₹1,00,000 @ 18% GST → Input CGST = ₹9,000, Input SGST = ₹9,000 (Total ₹1,18,000).
  • 01-Apr (Sales F8): Sold goods ₹2,00,000 @ 18% GST → Output CGST = ₹18,000, Output SGST = ₹18,000 (Total ₹2,36,000).
  • Set Off:
    • CGST Payable: ₹18,000 − ₹9,000 = ₹9,000
    • SGST Payable: ₹18,000 − ₹9,000 = ₹9,000
    • Total Net Cash Payable = ₹18,000

Scenario 2: Interstate Purchafrom + Local Sale (Cross-Utilization)

  • Purchase: ₹5,00,000 from Gujarat Supplier → Input IGST = ₹90,000.
  • Sales: ₹6,00,000 to Maharashtra Customer → Output CGST = ₹54,000, Output SGST = ₹54,000.
  • Set Off Order:
    1. IGST Credit (₹90,000) used against CGST Liability (₹54,000) → CGST Payable becomes Nil.
    2. Remaining IGST Credit (₹36,000) used against SGST Liability (₹54,000).
    3. SGST Payable = ₹54,000 − ₹36,000 = ₹18,000.

Scenario 2 Settlement Summary:

Tax Head Output Liability (₹) IGST Credit Utilized (₹) Net Cash Payable (₹)
CGST 54,000 54,000 Nil
SGST 54,000 36,000 18,000
IGST Nil Nil Nil

Purchases: Local ₹3,00,000 (CGST ₹27,000 + SGST ₹27,000) | Interstate ₹2,00,000 (IGST ₹36,000).

Sales: Local ₹8,00,000 (CGST ₹72,000 + SGST ₹72,000) | Interstate ₹5,00,000 (IGST ₹90,000).

Tax Head Output Liability (₹) Available ITC (₹) ITC Utilized (₹) Final Tax Payable (₹)
IGST 90,000 36,000 36,000 (IGST) 54,000
CGST 72,000 27,000 27,000 (CGST) 45,000
SGST 72,000 27,000 27,000 (SGST) 45,000
Total 2,34,000 90,000 90,000 1,44,000

TallyPrime ITC Set Off Process (GSTR-3B)

  1. Go to Gateway of Tally → Display More Reports → GST Reports → GSTR-3B.
  2. Navigate to the bottom tax liability section and select Set Off Tax Liabilities.
  3. TallyPrime automatically evaluates statutory credit hierarchies and allocates available ITC against respective tax heads.
  4. Verify ledger balances under GST Computation to confirm reduced asset/liability balances.

Verification Reports, Common Mistakes & FAQs

Reports to Verify in TallyPrime:

  • GST Computation: Real-time overview of gross output liability, available input credit, and net payable.
  • GSTR-3B: Reconcile eligible ITC allocation and tax payment schedules.
  • Duties & Taxes Ledgers: Verify that input tax balances are reduced by the set-off amounts.

Common Mistakes:

  • Attempting to set off CGST credit against SGST liability (prohibited by GST law).
  • Passing manual, unlinked Journal entries instead of using the statutory set-off workflow in GSTR-3B.
  • Claiming blocked or ineligible credits without review.
  • Ignoring the statutory priority of IGST credit utilization (which must be exhausted before CGST/SGST credits).

Frequently Asked Questions:

  • Q: ITC set off kab execute is?
    A: GST return file karne and net tax liability pay karne from pehle.
  • Q: Kor CGST credit SGST liability ke against ufrom ho sakta hai?
    A: Nahi, CGST credit only IGST and CGST liability ke against ufrom ho sakta is.
  • Q: TallyPrime in auto set off kahan is?
    A: GSTR-3B → Set Off Tax Liabilities screen par.
