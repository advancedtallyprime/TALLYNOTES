Core Concept: E-Invoice, IRP & Components

E-Invoice (Electronic Invoicing): B2B sales invoices and credit/debit notes ke data ko Invoice Registration Portal (IRP) par electronically transmit karke digital authentication, 64-character IRN, and digitally signed QR Code prapt karne ka standardized process is.

Important Rule:
E-Invoice ka matlab only PDF or electronic billing nahi hai; iska matlab government IRP portal from invoice data ka online authentication and unique IRN generation is.

Core Components of an E-Invoice

  • IRN (Invoice Reference Number): 64-character ka unique cryptographic hash value jo IRP dwara generate is.
  • Digitally Signed QR Code: IRP dwara return kior gaor encrypted 2D barcode jisme Supplier/Buyer GSTIN, Invoice No., Date, Taxable Value, Total Tax, HSN, and IRN embedded is.
  • Digital Signature: IRP ka cryptographic authentication proof jo document validity establish karta is.
  • Ack N& Ack Date: IRP portal par invoice register hone ka statutory timestamp.

Normal Invoice vs E-Invoice Comparison

Particular Normal Invoice E-Invoice
Created By Business Accounting Software Business Accounting Software
GST IRP Validation No Yes (Online API validation)
IRN (64-character hash) No Yes (Mandatory)
Signed QR Code No (or static UPI QR) Yes (IRP Digitally Signed QR)
Applicability All Registered/Unregistered dealers Turnover threshold cross karne wale B2B businesses

Company Setup & E-Invoice Feature Activation

Company Setup

  • Company: ABC Traders (Maharashtra) | Registration: Regular | FY: 2026–27

Enabling E-Invoice in TallyPrime:

  1. Press F11 (Features) → Set Enable Goods and Services Tax (GST) to Yes.
  2. Inside GST Details screen:
    • Set e-Invoicing applicable to Yes.
    • Applicable from: 01-Apr-2026.
    • Bill from Place: Mumbai.
    • Default period for e-Invoice report: 3 Days (or as required).
    • Send e-Way Bill details with e-Invoice: Yes (if applicable).
  3. Press Ctrl + A to save.

Practical Walkthrough: E-Invoice Generation in TallyPrime

Scenario 1: Interstate B2B Sales (Gujarat Electronics Pvt Ltd)

01-Apr-2026: Sold 10 Nos Laptops @ ₹50,000 = Taxable ₹5,00,000 + 18% IGST (₹90,000) = Invoice Total ₹5,90,000.

  1. Go to Gateway of Tally → Vouchers → Press F8 (Sales).
  2. Select Party: Gujarat Electronics Pvt Ltd → Sales Ledger: Sales - 18%.
  3. Select Item: Laptop (10 Nos @ ₹50,000) → Select IGST (₹90,000).
  4. Set Provide e-Invoice details: Yes (Verify Bill-to and Ship-to details).
  5. Save voucher → Prompt appears: Generate e-Invoice? Yes/No → Select Yes.
  6. TallyPrime securely exchanges JSON payload with IRP via API credentials and fetches the 64-character IRN, Ack No., and QR Code.

Scenario 2: Local B2B Sales (Mumbai Retail Pvt Ltd)

Sold goods worth ₹5,00,000 + 18% GST (CGST ₹45,000 + SGST ₹45,000) = Total ₹5,90,000.

  • Process invoice through F8 (Sales) → Auto-generate IRN → Preview invoice to confirm embedded dynamic QR code and IRN print headers.

Scenario 3: High-Value Interstate Sales (Delhi Electronics)

Sold goods worth ₹10,00,000 + 18% IGST (₹1,80,000) = Total ₹11,80,000 → Generated simultaneous E-Invoice + E-Way Bill.

E-Invoice Cancellation & Error Handling

Cancellation Protocol:

  • Time Window: E-Invoice ko IRP portal par generation ke 24 ghante ke andar cancel kior ja sakta is.
  • No Re-generation on Same Invoice No.: Ek baar cancel hone ke baad same invoice number par new IRN generate nahi ho saktNew invoice number ke saath fresh entry karni padti is.
  • TallyPrime Steps: Open e-Invoice Report → Select voucher → Press F10 (Cancel IRN) → Select cancellation reason (e.g., Wrong Customer / Data Entry Error) → Send update to IRP.

Common Validation Errors & Troubleshooting:

Error Description Root Cause Resolution in TallyPrime
Invalid GSTIN / Inactive GSTIN Buyer GSTIN mistyped or cancelled Verify GSTIN on portal and alter Party Ledger
Missing HSN Code / Invalid UQC Stock item master incomplete Enter 4/6/8-digit HSN and select standard UQC (e.g., NOS)
Pin Code Mismatch with State Pin code does not belong to party state Correct dispatch/delivery pin code in address details
Duplicate IRN Generated Same invoice number submitted again Change invoice numbering prefix/series

Verification Reports, Common Mistakes & FAQs

Verification Reports in TallyPrime:

  • e-Invoice Report (Alt + G → e-Invoice): Overview of IRN Generated, Pending for Generation, Rejected by IRP, and Cancelled.
  • e-Invoice Exception Report: Real-time listing of master-level errors preventing IRN creation.
  • Sales Register & Print Preview: Confirm that the 64-character IRN and 2D QR Code render on the printed tax invoice document.

Common Mistakes:

  • Issuing invoices to customers without printing the authenticated IRP QR code and IRN.
  • Attempting to manually edit an invoice in Tally after an IRN has already been generated.
  • Using dummy/incorrect HSN codes or non-standard Units of Measure.
  • Confusing E-Invoice generation with monthly GST return filing.

Frequently Asked Questions:

  • Q: IRN ka full form kor hai and iski length kitni is?
    A: Invoice Reference Number — yeh 64-character ka unique alphanumeric hash code is.
  • Q: E-Invoice generate hone ke baad invoice cancel karne ki time limit kor hai?
    A: IRP portal par invoice ko generation ke 24 ghante ke andar cancel kior ja sakta is.
  • Q: Kor B2C (unregistered consumers) transactions ke liye E-Invoice mandatory hai?
    A: Nahi, standard E-Invoice reporting provisions only B2B supplies, exports, and commercial B2B credit/debit notes par apply are.
