1. Core Concept

Enabling Security Control is the foundational step that activates password authentication, user role definitions, and access logs in a TallyPrime company.

2. How to Enable Security Control

Path to Enable Security: Gateway of Tally → Press Alt + K (Company Menu) → Select Security.
Alternative: During new company creation, press F12 → Enable Provide Security Details.

Step-by-Step Activation:

  1. Press Alt + K → Security.
  2. Select the active company.
  3. Set Control User Access to Company Data to Yes.
  4. Define the Administrator Credentials:
    • Username (Administrator): E.g., admin
    • Password: Strong alphanumeric password (e.g., Adm!n@9026)
    • Confirm Password: Re-enter the exact password.
  5. Review the prompt: Warning: Forgetting your password will render your data completely inaccessible!
  6. Set Enable Tally Audit to Yes (allows auditors to verify altered entries).
  7. Set Disallow opening in Educational Mode to Yes (prevents data from being opened on unlicensed systems).
  8. Press Ctrl + A to save. TallyPrime reloads and prompts for the admin login immediately.
Critical Warning: Tally does not provide a "Forgot Password" reset link for company administrator passwords! Always record credentials in a secure company password vault.

3. Interview Questions & Answers

Q1. What shortcut opens the Company menu in TallyPrime to access Security settings?

Ans: Alt + K opens the Company Menu.

Q2. What is the impact of enabling "Disallow opening in Educational Mode"?

Ans: It prevents unauthorized individuals from copying company data files and opening them on unauthorized PCs using free Educational Tally mode.
