1. Core Concept

After defining User Roles, the administrator assigns unique User Accounts with individual usernames and passwords to each employee. This establishes individual accountability and ensures an authentic audit trail.

2. Creating Users in TallyPrime

Navigation: Gateway of Tally → Press Alt + K → Users and Passwords.

3. Password Policy & Security Governance

  • Password Expiry: Force users to change passwords every 60 or 90 days via Password Policy settings.
  • Complexity Standards: Mandate minimum 8 characters with at least one uppercase letter, number, and special character.
  • Lockout on Failed Logins: Automatically lock accounts after 3 consecutive invalid password attempts.

4. Interview Questions & Answers

Q1. How can an employee change their own login password in TallyPrime?

Ans: Press Alt + K → Select Change Password → Enter existing password → Enter and confirm new password.
