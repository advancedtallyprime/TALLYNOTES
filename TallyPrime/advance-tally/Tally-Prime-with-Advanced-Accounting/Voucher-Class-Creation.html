1. Core Concept

Voucher Class: A powerful automation sub-feature within TallyPrime’s Voucher Types that pre-defines ledgers, payment methods, calculations, and tax duties during transaction entry.

Why Use Voucher Classes?

  • Eliminates Manual Selection: Pre-loads specific ledgers (e.g., Sales, Purchase, CGST, SGST, Freight) so users don't have to choose them on every invoice.
  • Automates Tax & Calculations: Calculates percentage-based additions/deductions automatically.
  • Prevents Human Error: Restricts options to appropriate modes (e.g., ensuring a Cash Payment voucher class only permits Cash ledgers).
  • Speeds Up Invoicing: Speeds up data entry for high-volume operations like Point of Sale (POS) and GST billing.

2. How to Create a Voucher Class in TallyPrime

Step-by-Step Walkthrough:

  1. Go to Gateway of Tally → Alter → Voucher Type.
  2. Select the Voucher Type you want to customize (e.g., Sales, Purchase, Payment, or Receipt).
  3. In the Voucher Type Alteration screen, move down to the Name of Class field (located at the bottom right).
  4. Type a clear, descriptive name for your class (e.g., Local Sales GST or Cash Sales POS) and press Enter.
+-----------------------------------------------------------------------+
|                       VOUCHER TYPE ALTERATION                         |
| Name: Sales                                                           |
| Type of Voucher: Sales                                                |
|                                                                       |
| ...                                       Name of Class               |
|                                           --------------------------- |
|                                           Local Sales GST             |
+-----------------------------------------------------------------------+

Configure the Voucher Class Classifications Screen:

  • Exclude / Include Groups: Specify which ledger groups are restricted or allowed (e.g., Include only Cash-in-Hand or Bank Accounts).
  • Default Accounting Ledger: Select the primary ledger to use automatically (e.g., Sales Account).
  • Additional Ledger Allocations (Auto-Calculations):
    • List additional ledgers like CGST, SGST, or Freight Charges.
    • Set the Calculation Type (e.g., As Total Amount Rate, On Current Subtotal, or Flat Rate).

Press Ctrl + A to save the class, and Ctrl + A again to save the Voucher Type.
