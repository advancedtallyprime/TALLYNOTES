1. Core Concept

  • Cost Centre: An organizational unit, department, location, or project to which expenses or incomes are allocated to monitor department-wise profitability and spending.
  • Cost Category: Used to classify cost centres into logical groups when you need to track expenses across parallel dimensions (e.g., tracking expenses by Department and by Project simultaneously).
  • Cost Centre Classes (Pre-defined Percentages): A feature in TallyPrime that allows you to automate percentage-based allocation (e.g., automatically splitting Direct Expenses as 80% Factory, 10% Stores, and 10% Packaging) without typing percentages manually during voucher entry.

2. Feature Activation in TallyPrime

Step A: Enable Cost Centres

  1. Press F11 (Features) on the Gateway of Tally.
  2. Set Enable Cost Centres to Yes.
  3. Press Ctrl + A to save.

Step B: Create Categories & Cost Centres

  1. Gateway of Tally → Create → Cost Category (e.g., Direct Expenses Category and Indirect Expenses Category).
  2. Gateway of Tally → Create → Cost Centre:
    • Create Factory, Stores, and Packaging under Direct Expenses Category.
    • Create Office and Marketing under Indirect Expenses Category.

Step C: Set Up Cost Centre Classes (Automated % Allocation)

  1. Gateway of Tally → Alter → Voucher Type → Payment.
  2. Scroll to the field Name of Class at the bottom right and type a class name (e.g., Direct Expense Class).
  3. Set allocations:
    • Factory: 80%
    • Stores: 10%
    • Packaging: 10%
  4. Create a second class named Indirect Expense Class:
    • Office: 75%
    • Marketing: 25%
  5. Press Ctrl + A to save.

5. Checking Reports & Verifying Breakdown

1. View Cost Centre Breakup Reports:

  • Navigation Path:
    Gateway of Tally → Display More Reports → Statements of Accounts → Cost Centres → Category Summary / Cost Centre Breakdown
    (Shortcut: Press Alt + G → Type Cost Centre Summary)

2. To Check / Delete / Modify Payment Entries:

  • Navigation Path:
    Gateway of Tally → Display More Reports → Statements of Accounts → Statistics → Payment
    OR: Gateway of Tally → Display More Reports → Account Books → Payment Register
  • Action: Select the month → Press Enter on the payment voucher to inspect or alter details. Press Alt + D inside the voucher to delete it.
